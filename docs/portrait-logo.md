# Portrait logo

Generated with the built-in image generation tool from `public/assets/me.png`. This is a stylised portrait emblem, not a replacement photograph.

## Files

- `public/assets/portrait-logo-source.png`: original generated image, preserved.
- `public/assets/portrait-logo.png`: 256px site logo.
- `app/favicon.ico`: 16px, 32px, and 48px favicon representations.
- `app/icon.png`: 192px icon.
- `app/apple-icon.png`: 180px Apple touch icon.

The source is resized and packaged by `node scripts/export-brand.mjs` using Sharp. No facial editing is performed by that export script.

## Generation prompt

Use case: identity-preserve / logo-brand. Create a single polished portrait logo for Acha Solomon Ona, using the supplied photograph as the identity reference. Preserve his recognisable short natural hair, beard shape, facial proportions and features. Transform only the portrait treatment: a crisp minimal vector-like head-and-shoulders emblem, facing forward with subtle three-quarter angle as in the photo, no hand. Professional black/navy suit silhouette. Restrained emerald teal #00d5a0 and pale ivory linework/flat fills, bold simple shapes and negative space that remain legible at favicon size. Circular emblem composition, centered in a square canvas with transparent outer background and a dark near-black #080e11 circular disc behind the portrait. Avoid photorealism, fine shading, gradients, tiny details, background scene, text, letters, watermarks, mockups, extra symbols. This is one finished logo asset, not a presentation sheet. Recognisable identity first; clean corporate engineering brand.
